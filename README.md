# pd_sopromat

Суррогатное моделирование связанной термо-механо-деградационной задачи: эталонный МКЭ-решатель,
обученный на нём суррогат, движок разделения временных масштабов и измерительная обвязка,
которая не даёт результатам соврать.

## Что это

2D-пластина с концентратором под циклической термомеханической нагрузкой. Три взаимодействующих
процесса: нестационарная теплопроводность, упругость с температурным расширением, накопление
повреждаемости по Качанову–Работнову, деградирующее жёсткость и теплопроводность.

Прямой расчёт такой задачи на длительный срок эксплуатации невозможен: напряжения живут на масштабе
секунд, повреждаемость — на масштабе лет. Проект измеряет, какой ценой этот разрыв закрывается —
и где проходит граница честного утверждения «точно и быстро одновременно».

## Что утверждается и что нет

| Утверждается | Не утверждается |
|---|---|
| Солвер **верифицирован** (MMS, Кирш, аналитика KR) | Солвер **валидирован** — сравнения с экспериментом нет |
| Измеренное ускорение при контролируемой невязке | Ускорение без указания базовой линии |
| «Циклы до потери 10% жёсткости» — сетко-сходящаяся метрика | «Циклы до разрушения» — величина сетко-зависима |
| Индикатор доверия с измеренным ROC | «Детектор OOD» — надёжно детектировать OOD нельзя |

Развёрнуто — в плане проекта, раздел «Что мы утверждаем и чего не утверждаем».

## Установка

```bash
uv sync                      # ядро + dev: солвер, верификация, тесты
uv sync --extra data         # + хранилище датасетов (Zarr, Arrow)
uv sync --extra ml           # + обучение (PyTorch, neuraloperator) — Ubuntu/CUDA
uv sync --extra api          # + FastAPI
```

Расчётная и деплой-платформа — Ubuntu 24.04. Разработка ведётся и на Windows; расхождение
окружений удерживается единым lockfile'ом. Под WSL2 датасеты держать только на Linux-ФС,
никогда под `/mnt/c`.

## Проверка

```bash
uv run pytest -q                            # быстрый набор
uv run pytest -m verification -q            # MMS, Кирш, аналитика Качанова–Работнова
uv run ruff check . && uv run mypy
```

## Структура

```
src/pdsopromat/
  core/        CaseSpec, State, единицы, хеширование конфигов
  physics/     определяющие соотношения, закон повреждаемости   ← единственный источник истины
  solver/      сборка на scikit-fem, staggered-связывание       ← эталон
  doe/         Sobol-выборка, манифесты
  dataset/     схема хранилища, версионирование
  surrogate/   модели, обучение, инференс                       ← не импортирует skfem
  multiscale/  прыжки по циклам, два контроллера ошибки, сертификация
  bench/       метрики, абляции, Парето, break-even
  api/         FastAPI — только оркестрация, ноль физики
web/           React + TS + Vite
```
